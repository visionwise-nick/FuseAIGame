三位一体核心架构：入口 · 平台 · 内容

分部估值对齐：合并报表自上而下拆为三块——硬件（入口掌机）；游戏内容销售（官方 IP／独占售卖与 DLC）；服务收费（AI 订阅/API 与 Fuse Store 抽成等与平台相关的经常性收入）。与右侧「分部估值」表行一一对应。

硬件入口 · Fuse 掌机

全球首款 AI 原生掌机

产品设计：不是把现有手游搬进掌机，而是围绕「AI 生成、实时互动、随手创作」重做入口。硬件预置 AI 游戏引擎、语音/图像输入、手柄与触控协同，让玩家能在掌机上完成从想法到可玩内容的第一步。

差异化点：Switch 的核心是独占内容，Steam Deck 的核心是 PC 游戏库，Fuse 的核心是 AI 原生交互入口。

独特点：硬件定义的不只是设备形态，而是 AI 游戏生成标准：输入方式、操作适配、创作反馈与内容分发从第一天打通。

Fuse Store：AI 驱动的 UGC 创作与分发

App Store 式商业闭环

产品设计：Fuse Store 承担 AI 游戏的创作工作台、内容商店和创作者后台。用户用自然语言生成游戏，平台自动完成模板匹配、资产生成、玩法调试、适配审核与上架分发。

差异化点：传统商店分发的是开发完成的游戏，Fuse Store 分发的是「可继续被 AI 改造的游戏种子」。

独特点：「游玩–创作–分享–变现」形成同一个闭环，玩家的每次二创都可能成为新供给，平台抽成、订阅和 API 服务形成持续收入。

Fuse IP · 游戏宇宙

官方基础游戏 · 全民 AI 设计

产品设计：官方 IP 不是封闭剧情，而是可被 AI 持续扩写的世界观底座。官方提供角色、世界观、美术风格和核心玩法，用户用 AI 修改关卡、NPC、剧情、任务与规则，生成属于自己的分支宇宙。

差异化点：任天堂依靠官方精品内容驱动购买，Fuse 在官方精品之上叠加全民共创，让 IP 生命周期由玩家持续延长。

独特点：每个官方 IP 都是一个可复用创作母体：官方负责质量与审美锚点，社区负责规模化扩展，最终沉淀为内容资产和用户关系资产。

PART 07 · DREAME MODEL

追觅科技的成功模式：从技术长板到全球品牌

Fuse 的关键不只是做一台掌机，而是用「核心技术 + 硬件产品 + 全球渠道 + 高端品牌」跑出消费电子公司的增长路径。追觅提供了可借鉴的中国硬科技出海样本。

成功关键：技术定义品类，品牌承接溢价

追觅的路径不是低价代工，而是把高速数字马达、算法控制、供应链工程和产品设计变成可感知的用户价值，再通过全球化品牌和渠道放大。这套模式证明：中国团队可以从底层技术切入，在高价值消费电子品类里建立品牌心智。

对应到 Fuse：AI 游戏引擎相当于核心技术长板，AI 掌机是可触摸的产品载体，Fuse Store 与官方 IP 是持续复购和品牌内容资产。

1 · 研发先行

先建立核心技术长板，再让产品围绕技术优势展开，而不是只拼外观和价格。

2 · 工程与供应链能力

把技术稳定地做进量产产品，形成体验、良率、交付和成本的综合优势。

3 · 高端品牌心智

通过设计、体验和内容表达建立高端感，让用户为真实差异化付费。

4 · 全球化渠道复制

从单一市场走向全球用户，用线上内容、零售渠道和社区口碑共同放大。

为什么这是 Fuse 成功的关键之一

AI 游戏生态需要一个强硬件入口承载体验，也需要全球化品牌承载信任。追觅模式的启发在于：用技术差异化切入高价值硬件，再用软件、内容和渠道持续放大用户生命周期价值。Fuse 要做的是把这套消费电子成功路径，升级到「AI 原生硬件 + UGC 平台 + IP 内容宇宙」的闭环。

定义：PS（市销率）= 该分部隐含股权或企业价值 ÷ 对应分部在统一口径下的年度营收（实操中常以 TTM 或 NTM/远期一年预测营收为分母；分部可加总时需避免收入重复计费）。常与可比公司的 P/S、EV/Sales 中位数／区间对照。

业态差异：低毛利、渠道型／代工型硬件长期在极低 PS带；品牌化主机与消费电子整机通常高于纯代工。内容与软件售卖更接近软件／发行／数字内容估值带。经常性的订阅、分成与平台抽成因利润率高、可复制性强，公开市场往往给显著更高的 PS／EV‑Sales（成长阶段常见区间上移），但个体差异极大。
